# Bundled recording credits

These FLAC files are unchanged copies from [Audio Compare’s track collection](https://github.com/kelvinlim/audio-compare/blob/main/assets/tracks/LICENSE).

## Bach — Goldberg Variations, BWV 988

Kimiko Ishizaka performed these pieces for the Open Goldberg Variations project in 2012. Both files are 24-bit / 96 kHz FLAC and were released under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).

- `goldberg-aria.flac`. [Aria at Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Goldberg_Variations_BWV_988_01_Aria.flac)
- `goldberg-variatio-1.flac`. [Variation 1 at Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Goldberg_Variations_BWV_988_02_Variatio_1_a_1_Clav.flac)

## Beethoven — String Quartet No. 6 in B-flat major, Op. 18 No. 6, I. Allegro con brio

The Musopen String Quartet performed this movement for the 2012 Musopen Kickstarter project. Musopen released the recording into the public domain. `beethoven-op18-6-i.flac` is a 24-bit / 48 kHz FLAC. [Recording and public-domain declaration at Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Beethoven_-_String_Quartet_No._6_in_B_flat_major,_Op._18_No._6_-_I._Allegro_con_brio_%28Musopen_String_Quartet%29.flac)
